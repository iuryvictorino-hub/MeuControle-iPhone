Não há conexão com bancos nem sincronização automática. No iPhone, dados deste link ficam separados dos dados do APK Android. Exporte um backup JSON regularmente; apagar dados do Safari ou remover o app pode apagar os registros.

Instalar no iPhone

Abra este link no Safari, toque em Compartilhar e escolha Adicionar à Tela de Início. Depois abra pelo ícone Meu Controle.

Os dados são salvos localmente neste aparelho. Para transferir do Android, crie um backup JSON no Android e importe em Ajustes > Restaurar cópia no iPhone.

Privacidade: o aplicativo não envia seus lançamentos para o GitHub. A internet é usada apenas para carregar e atualizar os arquivos do aplicativo.
